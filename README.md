# MediAssist – Medical Assistance Web Platform

MediAssist is a web application designed to simplify medical management for patients. It allows users to contact doctors, book medical appointments, and manage their medications and prescriptions from a single intuitive platform.

## 🚀 Features

### 👨‍⚕️ Doctor Interaction
- Search and view doctor profiles
- Contact doctors directly through the platform
- Book or request medical appointments (rendez-vous)

### 📅 Appointment Management
- Add, update, and delete your appointments
- View upcoming and past medical visits
- Receive reminders (optional if implemented)

### 💊 Medication Tracking
- Add your medications
- Track dosage, frequency, and duration
- Organize medications by type or time of day
- Store and view medical prescriptions

### 🗂️ User Dashboard
- Simple and clean interface
- Centralized management of health information
- Secure access to personal records

   `http://localhost:3000`
